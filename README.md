# ETRX — US Effective Tariff Rate Index

This repository holds the published site and data of **ETRX**, a rules-based monthly index of realized effective US tariff rates by country of origin and HS chapter, computed from official US Census Bureau trade data.

**Site:** https://svnbanker.github.io/etrx-site/

- `index.html` — the index page (latest print, full history, all series)
- `etrx.csv` — the full settlement panel, free to use with attribution
- `latest.json` — machine-readable latest print
- `RULEBOOK.md` — the complete methodology and governance rulebook

Everything here is generated automatically by the ETRX print engine on Census FT-900 release days. First prints are settlement values and are never restated; see the rulebook.

Research and commentary. Not investment advice.
